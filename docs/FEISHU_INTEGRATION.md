# 飞书接入指南

飞书能力作为可选适配器存在。业务核心不依赖飞书，便于本地演示、替换企业协作平台和减少权限范围。

## 支持范围

- 企业自建应用 SSO
- 隐患分派、逾期和复核通知
- 后续可扩展审批、多维表格和通讯录映射

## 配置步骤

1. 在自己的飞书开发者后台创建企业自建应用。
2. 只申请实际使用的最小权限。
3. 添加回调地址，例如 `https://your-domain.example/api/auth/feishu/callback`。
4. 复制 `.env.example` 为 `.env`，由部署平台注入真实配置。
5. 将 `FEISHU_MODE` 改为 `live` 后再测试。

## 建议权限

初始版本只需要身份认证和向指定会话发送消息的权限。不要为了开发方便一次性开放全组织通讯录、所有群消息或文档读取权限。

## 数据映射

本地用户表只保存业务所需的最小映射：本地用户 ID、飞书 Open ID、显示名和角色。Access Token 不应写入数据库或日志；需要缓存时使用有过期时间的密钥存储。

## 消息模板

通知中只放隐患编号、风险等级、截止时间和系统内链接。不要把完整事故描述、个人信息、附件原文或凭证发送到群聊。

## 开发与测试

默认模拟模式返回 `demo_` 前缀对象，不会向飞书发送请求。正式环境应使用专门的测试租户、测试群和最小权限应用完成联调。

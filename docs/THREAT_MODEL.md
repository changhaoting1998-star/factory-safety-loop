# 威胁模型

## 保护对象

- 员工身份与组织关系
- 隐患、事故和整改材料
- 飞书应用凭证与会话标识
- 内网服务与部署拓扑

## 主要风险

- 把生产备份、日志或附件误提交到公共仓库
- 在源码或前端构建产物中硬编码 App Secret
- 飞书应用申请过宽权限
- 通知消息在群聊中暴露完整事故细节
- 回调接口缺少 state 校验或会话保护
- 访问日志记录授权码、Token 或完整请求体

## 当前控制

- 默认合成数据和飞书模拟模式
- 环境变量配置与 Git 忽略规则
- 自动隐私扫描
- 后端代理外部 API，前端不接触 App Secret
- 通知正文限制长度并建议最小化内容

## 上线前必须补齐

- 正式会话、CSRF/state 校验和权限模型
- 数据库存储加密、备份策略与留存期限
- 审计日志脱敏与访问控制
- 限流、输入校验和安全响应头
- 飞书回调签名/事件验证（如启用事件订阅）
- 依赖、容器和基础设施安全扫描
